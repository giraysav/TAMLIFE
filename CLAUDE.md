## Otomatik commit (2026-10-20 kullanıcı kararı)

- İş bitince (testler geçip canlıya alındıktan sonra) **sormadan commit at**. Push yalnız kullanıcı isterse.
- Commit yalnız o işte **senin** değiştirdiğin dosya/satırları içerir. Başka oturumun commit edilmemiş değişikliği olan dosyayı katma; aynı dosyada karışıksa yalnız kendi parçanı index'e al (`git hash-object -w` + `git update-index --cacheinfo`) ve kullanıcıya hangi dosyanın neden dışarıda kaldığını yaz.
- Asla: `backend/.env` ve sırlar, `backend/var/`, `backend/data/reports/` (canlı müşteri raporları), derleme çıktıları; `git add -f` yok.
- Mesaj Türkçe `tür(alan): özet` + madde listesi + `Co-Authored-By`. `--no-verify` / amend yok. Kırmızı testle commit yok (şu an bilinen kırık test YOK: 908/908, arayüz 231/231).

## Mimari kurallar (çapraz)

- **Paketler** `backend/app/`: `yonetim/` (admin), `tampon/` (Veri Girişi: kaynak → tampon → analiz → dağıtım; Oracle/PG/katalog/TEMIP), `musteri/`, `rapor/`, `skor/`, `onedesk/`, `gelir/`, `gelir_uretim/`, `takvim/`, `proje/`, `sunum/`, `radar/`, `ekip/`, `talep/`, `topoloji/`. `yonetim` ↔ `tampon` birbirini import etmez; `skor` ← `musteri` ← `rapor`. Ortak: `ortak.py`, `ariza.py`, `db.py`, `catalog.py` (modüllerin TEK tanımı).
- **Hata sözleşmesi:** servis hatası `ortak.UygulamaHatasi(kod, mesaj)` alt sınıfı; router'da try/except yazma, fırlat. Başarı `{"status":"success","data":...}`, hata `{"detail":...}`. Durum değiştiren istek `x-csrf-token` ister. Yeni uç → test.
- **Denetim:** `audit_log.remember` commit SONRASI (açık yazma varken SQLite kilidi). Yakalanmayan hata `fault_event`e kod + kayıt no ile düşer.
- **DB:** panel DB (`models.Base`, Alembic `backend/alembic`, açık `op.create_table/add_column`, revizyon `app.models` import etmez, idempotent: var olan sütun/indeksi atla) + kişi başına SQLite (`KullaniciBase`: takvim, SMS/APN gelir; `create_all`). Model değişikliği → yeni revizyon (`test_alembic` yakalar). Yeni tablo `TABLE_OWNER`a. SQLite: WAL, busy_timeout 30 sn; "yoksa ekle" deseninde `db.yazma_kilidi`. `async def` uçta G/Ç yok (`run_in_threadpool`). Çok satır okuyan ağır uç önbellek/tek sıra ister (GIL konvoyu): bkz. `ekip/api._KILIT`, `onedesk.servis.top10` önbelleği, `app/isitici.py` (panel açılışında ve 60 sn'de bir ağır özetleri ısıtır).
- **Müşteri alanı** (`app/musteri_alani.py`): `customer.modul` = musteri | toptan | baglantili; `X-Musteri-Alani` başlığına göre TÜM Customer ORM sorguları süzülür; başlık yoksa musteri. Ham SQL ile customer okuyan kod alanı kendisi süzmeli. Arayüz başlığı `lib/http.musteriAlaniBasligi`. **WHOLESALE → Toptan, CONNCAR → Bağlantılı Araçlar (2026-10-20; `musteri_alani.SEGMENT_ALANI`):** çatı kartın segmenti WHOLESALE ise kart iştirakleriyle `toptan` alanına geçer, WHOLESALE'den çıkınca döner; ekranda Toptan yalnız WHOLESALE, Bağlantılı yalnız CONNCAR, Müşteri Yönetimi SMB/SA/MA/PA seçer (`musteri.servis.alan_segmentleri`, kart açma/düzenleme 400; Toptan'da segmentsiz kart WHOLESALE) (flush kancası `musteri_alani._segment_alani`; tüm yazım yolları; mevcutlar Alembic `0018`); yanıtta `modul`, arayüz kartı yeni modülde açar (`musteri-yolu.modulYolu`). Kart eşleşmesi (TEMIP harita/bağlama, sayaçlar, elle atama, Radar, ham müşteri ve eski panel aktarımı) `@musteri_alani.tum_alanlarda` ile tüm modüllerde çalışır.
- **Tek personel kümesi** (`kullanicilar.personel()` / `personel_mi` / `personel_kosulu`): etkin TeamMember, admin değil. TeamMngr ve admin hiçbir kişi listesinde/hesapta yok.
